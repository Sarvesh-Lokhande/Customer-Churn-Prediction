# Customer Churn Prediction System

A Flask-based machine learning application that predicts customer churn
and provides explanations and retention recommendations.

## Features

- Individual customer churn prediction
- Churn probability and risk classification
- SHAP-based model explanations
- Customer retention recommendations
- Customer dataset analysis
- CSV upload and prediction export
- Revenue-at-risk estimation

## Technologies

- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- SHAP
- HTML and CSS

## Requirements

- Python 3.10
- pip
